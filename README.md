Технологический стек

- HTML5 — семантическая разметка, современные API

- CSS3 — Flexbox, Grid, CSS Custom Properties (переменные)

- JavaScript (ES6+) — нативный JS без фреймворков

- Responsive Web Design — адаптивная вёрстка под все устройства

 Инструменты разработки
- Visual Studio Code — основная среда разработки

- Git & GitHub — контроль версий и хостинг репозитория

- Node.js & npm — среда выполнения и менеджер пакетов

- Figma — проектирование интерфейсов и дизайн-макеты

 Расширения VS Code
- Live Server — локальный сервер с автоматическим обновлением (hot reload)

- Prettier — автоматическое форматирование кода

- Auto Rename Tag — синхронное переименование парных тегов

- GitLens — расширенные возможности работы с Git

- ES6 String HTML — подсветка HTML в JavaScript строках

- Figma to Code — интеграция с дизайн-макетами Figma
