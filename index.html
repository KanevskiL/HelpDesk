Популярные темы

  • Как восстановить доступ к панели управления?
    Чтобы восстановить доступ, нажмите «Забыли пароль» на странице входа и следуйте инструкциям для сброса пароля. Проверьте папку «Спам», если письмо не пришло.
  • Где найти ключи API для бота?
    Ключи API находятся в разделе «Интеграции» → «API-ключи». Создайте новый ключ, установите права доступа и сохраните его в безопасном месте.
  • Лимиты бесплатного тарифного плана
    Бесплатный тариф включает 3 проекта и до 1000 запросов в месяц. Для дополнительных возможностей просмотрите платные планы в разделе «Тарифы».
